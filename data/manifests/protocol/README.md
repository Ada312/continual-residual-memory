# EARS-D protocol metadata

These files contain no audio. They pin the lightweight inputs required by
`data/prepare_ears_d.py`:

| File | Origin |
| --- | --- |
| `ears_benchmark_v1_test_files.json` | EARS benchmark `test_files.json` |
| `demand_16k_index.csv` | Frozen 16 kHz DEMAND index produced by the SETTA EARS-D indexing protocol |

The EARS-derived selection remains subject to the upstream CC BY-NC 4.0
terms. SETTA and DEMAND terms continue to apply to the frozen index. See
[`THIRD_PARTY.md`](../../../THIRD_PARTY.md).
